# PySimpleManager

## Установка и запуск

1. Установщик - на странице **Releases** репозитория. Тип установщика выбирается в зависимости от ОС.
2. Запуск - ярлык **"PySimpleManager"**. Откроется браузер на `http://127.0.0.1:8765`. Окно консоли закрывать нельзя.
3. Для расширения Chrome установка аналогичная REG.RU TPD Helper . При загрузке новой версии программы достаточно перезагрузить расширение во вкладке chrome://extenions
4. Войдите в manager в этом же браузере. В шапке программы появится зелёная точка и "manager: расширение подключено". 
5. После установки расширения можно перейти в его настройки нажав на иконку в правом верхнем углу, а затем на кнопку **Настройки** . Выставить для поля **Закрывать вкладку manager через, секунд (0 - не закрывать)** значение в 0, **Пауза между доменами, мс** тоже в 0 .

## Рабочее место

### Новое дело

Окно для обработки документов. Перетащить документы можно любого типа в выделенную область. Файлы из архивов .zip/.rar распаковываются автоматически и распределяются в категории. Файлы между категориями можно перемещать вручную.

### Окно "Домены"

- Домены из заявления загружаются из manager сами после проверки дела. Список можно поправить и нажать **Загрузить из manager** - запросятся только новые домены. **Сбросить** - следующая загрузка запросит все домены заново. В правой части панели отображается статус автоматической проверки полей заявлений.
- Карточка домена: администратор, паспорт или ИНН, ЕСИА, последняя смена администратора, provider, аккаунт, логин и
  e-mail аккаунта, отметки «стоп», «внимание», «к сведению».
- Галка у домена - участвует ли он в смене.
- Кнопки домена:
  - **Sd** - поля Sd и S;
  - **ESIA** - сверка Sd с данными Госуслуг;
  - **MO** - сверка Sd с базовой анкетой владельца аккаунта;
  - **К** - комментарий администратора в S;
  - «в поиск» - значение в строку «Поиск»;
  - **«→ ЛК»** - окно «Смена владельца ЛК» с аккаунтом этого домена.

## Вкладка "Домены в manager"

Данные списка доменов без дела. Домены вписываются через пробел, запятую или с новой строки.

| Кнопка                      | Что делает                                                                                                                                                                                   |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Загрузить данные из manager | Загрузить Sd, S, ЕСИА и MO(Matches account owner).                                                                                                                                           |
| Остановить                  | Прервать загрузку                                                                                                                                                                            |
| Выгрузка по доменам (HTML)  | Отдельный HTML-файл: итог по группам, администраторы, e-mail, таблица доменов с фильтром. Если доменов много позволяет сверить данные администратора для каждого и разбить на группы персон. |
| Сбросить результат          | Стереть сохранённый результат: следующая загрузка запросит все домены заново                                                                                                                 |

Домены в таблице идут по «проблемности»: сначала свободные и с расхождениями, в конце - в порядке. Кнопки ESIA и MO открывают окна сверки.

## Вкладка "Смена владельца ЛК"

1. **Текущий владелец.** Базовая анкета из manager рядом с данными заявления (их вписывает оператор), итог по
   каждому полю. Тип анкеты (физлицо, ИП, юрлицо) выбирается сам.
2. **Новый владелец.** Выберите физлицо, ИП или юрлицо, заполните поля → **"Заполнить автоматически"**: программа откроет в Chrome «Базовая анкета пользователя #…» впишет заполненные поля (пустые не трогает, тип анкеты переключит сама). **Сохранить** в manager нажимаете вы. **Очистить форму** - очистить поля.

## Где результаты

- Установленная программа - папка «Документы\PySimpleManager»: в `results\` - папки проверок (`report.html` -
  отчёт, `export.json` - выгрузка), `реестр_проверок.xlsx`, в `results\_workspace\` - дела рабочего места.
  Обновление и удаление программы эту папку не трогают.
- Запуск из исходников - `results/` в папке `doctool`.
